O que é um Sistema Operacional?

Conceito

O que é um Sistema Operacional?

Software responsável por gerenciar o hardware e fornecer serviços aos programas. É a camada entre o hardware e os aplicativos do usuário. Exemplos: Windows 10/11, Linux, Android, iOS, macOS.

Kernel (Núcleo)

É o núcleo central do sistema operacional. Gerencia diretamente o hardware (CPU, memória, dispositivos). Controla processos, memória, sistema de arquivos e comunicação. É a parte mais fundamental do SO.

Operações básicas com arquivos

Formatação, Sistemas de Arquivos e Criptografia

Conceito

Formatação, Sistemas de Arquivos e Criptografia

- Instalação e Formatação: Durante a instalação do SO, é necessário formatar a unidade de disco para preparar o dispositivo de armazenamento.
- NTFS (New Technology File System): Sistema de arquivos padrão e mais utilizado no Windows. Oferece controle de permissões, suporte a arquivos de grande tamanho e maior confiabilidade.
- BitLocker: Recurso opcional que realiza a criptografia completa do disco, protegendo toda a unidade de armazenamento contra acessos não autorizados.
- EFS (Encrypting File System): Permite criptografar arquivos e pastas específicos, oferecendo uma camada adicional de segurança.

Extensões de Arquivo

O nome do arquivo é composto por nome + extensão (ex.: documento.docx). Por padrão, o Windows oculta as extensões. Para exibi-las, vá em Explorador de Arquivos → Exibir → Extensões de nome de arquivo.

Destaque

Dica sobre extensões

Bizu

Dica sobre extensões

Saber as extensões ajuda a identificar o tipo de arquivo e qual programa abri-lo. Exemplo: .docx → Word, .xlsx → Excel, .pdf → Adobe Reader.
