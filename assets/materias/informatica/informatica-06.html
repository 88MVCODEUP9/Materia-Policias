O que é Software

Software é a parte lógica do computador – programas, dados e instruções que controlam o hardware e permitem a execução de tarefas. Diferente do hardware, o software não tem forma física.

Destaque

Ilustração de software vs hardware

Destaque

Classificação básica

Conceito

Classificação básica

Os softwares podem ser divididos em três grandes grupos:
- Sistema Operacional (gerencia o hardware)
- Aplicativos (ferramentas para o usuário)
- Utilitários (manutenção e segurança)

Destaque

O que é um Sistema Operacional

Conceito

O que é um Sistema Operacional

É o software base que controla o hardware, gerencia recursos (memória, processador, dispositivos) e serve de intermediário entre o usuário e o computador. Sem ele, o hardware não funciona.

Exemplos de SO

Função principal do SO

Bizu

Função principal do SO

SO = intermediário entre usuário e hardware. Gerencia processos, memória, arquivos e dispositivos.

O que são Aplicativos

Conceito

O que são Aplicativos

Programas que o usuário executa diretamente para realizar tarefas específicas. Rodam sobre o sistema operacional e dependem dele para funcionar.

O que são Utilitários

Conceito

O que são Utilitários

Softwares que auxiliam na manutenção, otimização, segurança e gerenciamento do sistema. Não são essenciais, mas melhoram o desempenho e a confiabilidade.

O que é Barramento

Conceito

O que é Barramento

Caminho (trilha elétrica) por onde os dados trafegam internamente na placa-mãe, conectando CPU, memória e periféricos. Quanto mais largo (número de bits), mais rápido o fluxo de dados.

Destaque

Esquema de barramentos

Destaque

Tipos de Barramento

Conceito

Tipos de Barramento

- Barramento de dados – transporta os dados propriamente ditos.
- Barramento de endereço – indica onde os dados devem ser lidos/escritos.
- Barramento de controle – sinais de comando (leitura, escrita, interrupção).

Quanto maior a largura (ex.: 32 bits, 64 bits), maior a velocidade de transferência.

Destaque

Barramento não é cabo externo

Pegadinha

Barramento não é cabo externo

Barramento refere-se a circuitos internos da placa-mãe, não a cabos USB ou HDMI.

Destaque

O que é Software Livre

Conceito

O que é Software Livre

Software que concede ao usuário quatro liberdades essenciais. Não se confunde com gratuito – a liberdade é o foco, não o preço.

Destaque

As 4 Liberdades do Software Livre

Conceito

As 4 Liberdades do Software Livre

Liberdade 0: executar o programa para qualquer propósito.
Liberdade 1: estudar como o programa funciona e adaptá-lo (exige acesso ao código-fonte).
Liberdade 2: redistribuir cópias para ajudar outras pessoas.
Liberdade 3: melhorar o programa e liberar as melhorias publicamente.

Destaque

Software Livre ≠ Gratuito

Bizu

Software Livre ≠ Gratuito

Livre = liberdade de uso, estudo, modificação e distribuição. Gratuito = custo zero. Um software pode ser gratuito mas não livre (ex.: muitos freeware).

Destaque

Software Livre é Open Source?

Pegadinha

Software Livre é Open Source?

Nem todo software de código aberto (open source) é considerado software livre pelos critérios da FSF, pois pode restringir redistribuição ou modificação. Mas, na prática, muitos usam os termos como sinônimos.

Destaque

Mnemônico rápido

Bizu

Mnemônico rápido

SO = base, Apps = uso, Utils = cuidado, Livre = liberdade.
