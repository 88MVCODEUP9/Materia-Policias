Win + R: comandos úteis

Use Win + R e digite:

  • %temp% → pasta de arquivos temporários
  • msconfig → configuração do sistema
  • cmd → Prompt de Comando
  • powershell → PowerShell
  • control → Painel de Controle

Atalhos para abrir

Direto: Ctrl + Shift + Esc

Indireto: Ctrl + Alt + Del → escolher 'Gerenciador de Tarefas'

Explicação

O que é um Sistema Operacional?

Software responsável por gerenciar o hardware e fornecer serviços aos programas. É a camada entre o hardware e os aplicativos do usuário. Exemplos: Windows 10/11, Linux, Android, iOS, macOS.

Explicação

Kernel (Núcleo)

É o núcleo central do sistema operacional. Gerencia diretamente o hardware (CPU, memória, dispositivos). Controla processos, memória, sistema de arquivos e comunicação. É a parte mais fundamental do SO.

Conceito

Representação do Kernel

Explicação

Driver (Controlador)

Programa que permite ao SO se comunicar com um dispositivo. Cada hardware precisa de um driver específico. Sem o driver correto, o dispositivo não funciona.

Explicação

Codec

Programa que codifica e decodifica arquivos de mídia. Necessário para reproduzir áudios e vídeos em determinados formatos. Exemplos: H.264, MP3, AAC, HEVC (H.265).

Bizu

Resumo rápido

Kernel = núcleo do SO | Driver = ponte entre SO e hardware | Codec = tradutor de arquivos de mídia

Explicação

Explorador de Arquivos (Windows Explorer)

Ferramenta principal para gerenciar arquivos e pastas. Atalho: Win + E. Anteriormente chamado de Windows Explorer, atualmente é Explorador de Arquivos.

Explicação

Limites do sistema

Caminho máximo: 260 caracteres (exemplo: C:\Users\joao\Downloads\PostaLA.PDF). Raiz do sistema: Windows (NTFS).

Explicação

Operações básicas com arquivos

  • Criar: clique direito → Novo → Pasta/Arquivo
  • Copiar: Ctrl + C ou clique direito → Copiar
  • Colar: Ctrl + V ou clique direito → Colar
  • Recortar: Ctrl + X ou clique direito → Recortar
  • Renomear: F2 ou clique direito → Renomear
  • Excluir: Delete (vai para Lixeira) ou Shift + Delete (exclusão permanente)

Explicação

Estrutura de Diretórios do Windows

  • Raiz (C:): diretório principal do sistema
  • Windows: arquivos do sistema operacional
  • Program Files: programas instalados (64 bits)
  • Program Files (x86): programas 32 bits
  • Users: dados dos usuários (Documentos, Downloads, etc.)
  • ProgramData: dados compartilhados de programas

Explicação

Busca e Localização

  • Barra de Busca: localizar arquivos e pastas rapidamente
  • Filtros: refinar busca por data, tipo, tamanho
  • Busca Avançada: operadores como 'data:>2023/01/01'
  • Indexação: Windows indexa conteúdo para buscas rápidas
  • Opções de Pesquisa: incluir conteúdo de arquivos, sistema, ocultos

Explicação

Visualização e Organização

  • Modos de Exibição: Ícones grandes/pequenos, Lista, Detalhes, Lado a lado
  • Ordenação: por nome, data, tipo, tamanho
  • Agrupar por: organizar por data modificada, tipo, etc.
  • Painel de Detalhes: informações do arquivo selecionado
  • Painel de Visualização: prévia do conteúdo
  • Navegador: árvore de diretórios à esquerda

Explicação

Configurações e Opções do Explorador

  • Exibir: mostrar/ocultar arquivos ocultos, extensões
  • Opções de Pasta: configurações de navegação
  • Personalizar: layout do explorador de arquivos
  • Acesso Rápido: pastas favoritas e recentes
  • Bibliotecas: agrupar pastas de diferentes locais

Explicação

Permissões e Segurança

  • Propriedades: clique direito → Propriedades
  • Segurança: permissões de acesso (ler, escrever, executar)
  • Atributos: somente leitura, oculto, arquivo
  • Compartilhamento: compartilhar pastas na rede
  • Criptografia: proteger pastas com senha (EFS)

Explicação

Formatação, Sistemas de Arquivos e Criptografia

  • Instalação e Formatação: Durante a instalação do SO, é necessário formatar a unidade de disco para preparar o dispositivo de armazenamento.
  • NTFS (New Technology File System): Sistema de arquivos padrão e mais utilizado no Windows. Oferece controle de permissões, suporte a arquivos de grande tamanho e maior confiabilidade.
  • BitLocker: Recurso opcional que realiza a criptografia completa do disco, protegendo toda a unidade de armazenamento contra acessos não autorizados.
  • EFS (Encrypting File System): Permite criptografar arquivos e pastas específicos, oferecendo uma camada adicional de segurança.

Explicação

Compactação e Backup

  • Compactar: reduzir tamanho de arquivos (ZIP, RAR)
  • Descompactar: extrair arquivos compactados
  • Backup de Arquivos: cópias de segurança importantes
  • Histórico de Arquivos: versões anteriores (Windows 10/11)
  • Restauração: recuperar arquivos excluídos ou modificados

Bizu

Bizu do Gerenciador

Win + E = Explorador de Arquivos | F2 = Renomear | Shift + Delete = Exclusão permanente | Bibliotecas = organização virtual de pastas

Explicação

Extensões de Arquivo

O nome do arquivo é composto por nome + extensão (ex.: documento.docx). Por padrão, o Windows oculta as extensões. Para exibi-las, vá em Explorador de Arquivos → Exibir → Extensões de nome de arquivo.

Bizu

Bizu

Dica sobre extensões

Saber as extensões ajuda a identificar o tipo de arquivo e qual programa abri-lo. Exemplo: .docx → Word, .xlsx → Excel, .pdf → Adobe Reader.
