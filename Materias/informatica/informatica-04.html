Hardware

8 min de leitura

Explicação

O que é Hardware

Hardware é o conjunto de componentes físicos de um computador ou dispositivo eletrônico. São partes tangíveis, que podem ser tocadas e vistas.

Conceito

Exemplo de hardware

Explicação

Exemplos de hardware

Processador, placa-mãe, memória RAM, placa de vídeo, SSD, HD, fonte de alimentação, cooler, monitor, teclado, mouse, webcam, impressora, placa de rede, placa de som.

Bizu

Bizu

Hardware = físico

Tudo o que você pode tocar no computador é hardware. Se não pode tocar, é software.

Explicação

Placa-mãe (Motherboard)

É a principal placa do computador. Permite a comunicação entre todos os componentes. Possui socket da CPU, slots de memória, slots PCI Express, conectores SATA, slots M.2, chipset, conectores de energia, USB, áudio, rede e firmware UEFI.

Conceito

Placa-mãe

Explicação

Chipset

Conjunto de circuitos que gerencia a comunicação entre a CPU, memória, periféricos e barramentos. Define quais tecnologias são suportadas (ex.: PCIe, USB, SATA).

Conceito

Chipset em placa-mãe

Explicação

CPU (Unidade Central de Processamento)

Principal componente responsável pelo processamento de instruções. Executa operações aritméticas, lógicas e de controle. Características: número de núcleos, threads, frequência, cache, arquitetura, consumo e tecnologia de fabricação.

Conceito

Processador (chip)

Explicação

Núcleos e Threads

Núcleo (core): unidade física de processamento. Ex.: 8 cores = 8 núcleos físicos.

Thread: linha de execução lógica. Ex.: 8 cores / 16 threads (cada core pode executar 2 threads simultaneamente com Hyper-Threading/SMT).

Explicação

Cache do processador

Memória extremamente rápida integrada à CPU, usada para armazenar dados frequentemente acessados. Níveis: L1 (mais rápido, menor), L2, L3 (mais lento, maior). Reduz a necessidade de acessar a RAM.

Conceito

Hierarquia de cache

Atenção

Pegadinha

CPU ≠ Gabinete

CPU é o processador (chip), não o gabinete do computador. Muitas pessoas confundem, mas são coisas diferentes.

Explicação

O que é RAM

RAM (Random Access Memory) é a memória de trabalho do computador. Armazena temporariamente dados e programas em uso. É volátil — perde os dados ao desligar.

Conceito

Pentes de RAM

Explicação

Gerações de RAM

DDR, DDR2, DDR3, DDR4, DDR5. Cada geração traz maior velocidade, menor consumo e maior capacidade. Não são compatíveis entre si (encaixes diferentes).

Atenção

Pegadinha

RAM ≠ Armazenamento

RAM é memória volátil de curto prazo; SSD/HD são armazenamento permanente. Não confunda os dois.

Explicação

GPU (Graphics Processing Unit)

Responsável pelo processamento gráfico e também por tarefas de processamento paralelo (ex.: inteligência artificial, mineração). Pode ser integrada (no processador) ou dedicada (placa separada).

Conceito

Placa de vídeo dedicada

Explicação

VRAM

Memória dedicada da GPU (Video RAM). Armazena texturas, imagens, buffers e dados gráficos. Quanto mais VRAM, melhor para jogos e aplicações pesadas.

Conceito

VRAM em placa de vídeo

Explicação

HD (Hard Disk Drive)

Armazenamento magnético com discos giratórios e cabeças de leitura/gravação. Características: grande capacidade, baixo custo por GB, partes móveis, maior latência, suscetível a impactos.

Conceito

HD interno

Explicação

SSD (Solid State Drive)

Armazenamento baseado em memória flash, sem partes móveis. Características: alta velocidade, baixa latência, silencioso, resistente a impactos, mais caro por GB que HD.

Conceito

SSD SATA e NVMe

Explicação

SSD SATA vs. NVMe

SSD SATA: utiliza interface SATA, formato 2,5 polegadas, desempenho limitado pela interface (até ~550 MB/s).

SSD NVMe: utiliza protocolo NVMe via PCI Express, desempenho muito superior (vários GB/s).

Explicação

M.2

M.2 é um formato físico de dispositivo. Pode ser SATA ou NVMe. Importante: M.2 ≠ NVMe. Existem M.2 SATA e M.2 NVMe.

Atenção

Pegadinha

M.2 não significa velocidade

M.2 é apenas o formato físico. A velocidade depende se é SATA ou NVMe. Sempre verifique o protocolo.

Explicação

Fonte de Alimentação

Transforma a energia da tomada em tensões adequadas para os componentes (+12V, +5V, +3,3V). Fornece energia, regula tensões, protege contra picos e distribui energia para todos os componentes.

Conceito

Fonte de alimentação ATX

Explicação

Principais linhas de tensão

  • +12V: para CPU, GPU, placa-mãe (conectores principais).
  • +5V: para USB, SSDs, periféricos.
  • +3,3V: para chipsets, RAM, alguns componentes.

Explicação

Refrigeração do computador

Componentes geram calor. O sistema de refrigeração remove esse calor para evitar superaquecimento. Inclui: dissipador, ventoinha, pasta térmica, heat pipes, radiador, bomba (water cooler).

Conceito

Air cooler vs Water cooler

Explicação

Cooler

Air cooler: dissipador de calor + ventoinha.

Water cooler: líquido circula para transportar calor até um radiador com ventoinhas.

Explicação

Pasta Térmica

Aplicada entre a CPU (ou GPU) e o cooler. Preenche imperfeições microscópicas das superfícies, melhorando a transferência de calor.

Conceito

Aplicação de pasta térmica

Bizu

Bizu

Thermal Throttling

Redução automática do desempenho (frequência) para controlar a temperatura. Ex.: temperatura alta → redução de frequência → menor consumo e calor.

Explicação

PCI Express (PCIe)

Interface de alta velocidade para conectar componentes como GPU, placa de rede, SSD NVMe, placas de captura. Versões: PCIe 3.0, 4.0, 5.0. Configurações: x1, x4, x8, x16 (quanto maior, mais largura de banda).

Conceito

Slots PCIe

Explicação

SATA

Interface para HDs, SSDs SATA e unidades ópticas. Atualmente na versão SATA III (6 Gb/s).

Explicação

M.2

Conector físico para SSDs (e outros dispositivos). Suporta SATA ou NVMe via PCIe.

Explicação

RAM DIMM

Slots para módulos de memória RAM. Normalmente 2 ou 4 slots por placa-mãe. Canais duais (dual channel) aumentam desempenho.

Explicação

UEFI (Unified Extensible Firmware Interface)

Firmware moderno que substitui a BIOS. Inicializa o hardware, executa o POST e carrega o sistema operacional. Interface gráfica, suporte a discos >2TB (GPT), inicialização mais rápida.

Conceito

Tela UEFI

Explicação

CMOS e Bateria

A placa-mãe tem uma bateria CR2032 que mantém as configurações da UEFI/BIOS e o relógio em tempo real quando o computador está desligado.

Conceito

Bateria CMOS

Atenção

Pegadinha

UEFI ≠ BIOS

UEFI é o sucessor da BIOS, com mais recursos. Muitos ainda chamam de BIOS, mas são diferentes.

Explicação

Dispositivos de Entrada

Enviam informações ao computador. Exemplos: teclado, mouse, microfone, webcam, scanner, controle, mesa digitalizadora.

Conceito

Teclado e mouse

Explicação

Teclado

Tipos: membrana, mecânico, tesoura, capacitivo. O mecânico é preferido por gamers e digitadores por feedback tátil e durabilidade.

Explicação

Mouse

Características: sensor (laser/óptico), DPI/CPI (sensibilidade), polling rate (taxa de atualização), botões, conectividade (com fio, Bluetooth, 2,4 GHz).

Explicação

Dispositivos de Saída

Apresentam informações ao usuário. Exemplos: monitor, impressora, projetor, caixa de som, fone de ouvido.

Conceito

Monitor e impressora

Explicação

Monitor

Características: tamanho (polegadas), resolução (Full HD, QHD, 4K), taxa de atualização (60Hz, 144Hz, 240Hz), tempo de resposta (ms), tipo de painel (IPS, TN, VA), brilho, contraste, conectores.

Explicação

Resolução

1920×1080 – Full HD

2560×1440 – QHD

3840×2160 – 4K UHD

Explicação

Taxa de atualização (Hz)

Número de quadros por segundo que o monitor pode exibir. Quanto maior, mais fluidez (ex.: 144Hz para jogos).

Explicação

Dispositivos de Entrada e Saída

Podem enviar e receber informações. Exemplos: tela touchscreen, armazenamento externo (pendrive, HD externo), placas de rede, impressoras multifuncionais.

Atenção

Pegadinha

Touchscreen é entrada e saída

A tela touchscreen exibe (saída) e recebe toques (entrada). É um dispositivo híbrido.

Explicação

USB

Interface universal para conectar teclado, mouse, pendrive, HD externo, webcam, impressora, celular, etc. Gerações: USB 2.0, 3.0, 3.1, 3.2, 4.0. Velocidades variam.

Conceito

Conectores USB

Explicação

USB-C

Tipo de conector físico reversível. Pode suportar USB 3.0, 3.1, 4.0, Thunderbolt, DisplayPort, etc. Não indica velocidade — apenas o formato.

Explicação

HDMI

Interface digital para vídeo e áudio. Comum em monitores, TVs, placas de vídeo, consoles. Versões: HDMI 1.4, 2.0, 2.1 (suporte a resoluções e taxas maiores).

Explicação

DisplayPort

Interface digital para monitores, similar ao HDMI, mas mais comum em computadores. Suporta altas resoluções e taxas de atualização.

Explicação

Ethernet

Tecnologia de rede com fio. Velocidades: 100 Mb/s, 1 Gb/s (Gigabit), 2,5 Gb/s, 5 Gb/s, 10 Gb/s.

Explicação

Placa de Rede

Permite comunicação com outros dispositivos via Ethernet, Wi-Fi ou outras tecnologias. Pode ser integrada à placa-mãe ou dedicada (PCIe).

Conceito

Placa de rede Ethernet

Explicação

Placa de Som

Processa sinais de áudio. Pode ser integrada à placa-mãe (áudio onboard), dedicada (PCIe) ou externa (USB).

Explicação

RAID (Redundant Array of Independent Disks)

Combina múltiplas unidades de armazenamento para melhorar desempenho, redundância ou ambos.

Explicação

Frequência

Medida em Hz, MHz, GHz. Ex.: 4 GHz = 4 bilhões de ciclos por segundo. Frequência maior não significa necessariamente maior desempenho — arquitetura também importa.

Explicação

Latência

Tempo para uma operação ser concluída. Presente em RAM, CPU, SSD, HD, GPU, rede. Menor latência = melhor resposta.

Explicação

Largura de Banda

Quantidade de dados transferida por segundo. Importante em RAM, VRAM, PCIe, armazenamento e redes.

Explicação

Temperatura

Componentes têm limites de temperatura. Superaquecimento pode causar: redução de desempenho, instabilidade, desligamento, danos permanentes.

Explicação

Overclock e Undervolt

Overclock: operar acima das especificações (aumenta desempenho, consumo e calor).

Undervolt: reduzir tensão (diminui consumo e temperatura, pode manter desempenho).

Explicação

Tipos de Computadores

  • Desktop: expansível, componentes padrão.
  • Notebook: portátil, componentes compactos.
  • Servidor: projetado para serviços e alta confiabilidade.
  • Workstation: alto desempenho para tarefas profissionais.
  • Mini PC: compacto, baixo consumo.
  • Sistema embarcado: hardware para função específica.

Explicação

Compatibilidade de Hardware

Antes de instalar, verifique:

  • CPU: socket, chipset, suporte da placa-mãe, BIOS/UEFI.
  • RAM: geração DDR, capacidade, frequência, compatibilidade.
  • GPU: PCIe, dimensões, fonte, conectores.
  • SSD: formato, interface, protocolo.
  • Fonte: potência, conectores, qualidade.

Bizu

Bizu

Resumo rápido

Hardware = físico. CPU = processador. GPU = gráficos. RAM = memória temporária. SSD/HD = armazenamento. Placa-mãe = liga tudo. Fonte = energia. Cooler = resfria. Periféricos = entrada/saída.
