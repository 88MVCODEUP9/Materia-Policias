O que é o macOS

O macOS é o sistema operacional desenvolvido pela Apple para seus computadores Mac.

Responsabilidades:

  • Gerenciar hardware
  • Executar aplicativos
  • Gerenciar memória e processos
  • Administrar arquivos e dispositivos
  • Controlar recursos de rede
  • Implementar mecanismos de segurança
  • Fornecer a interface gráfica ao usuário

🧠 Bizu: Mac = computador | macOS = sistema operacional do Mac

Logo do macOS

Sistemas Operacionais da Apple

A Apple possui diferentes sistemas operacionais para diferentes dispositivos:

Sistema Dispositivo
macOS Mac
iOS iPhone
iPadOS iPad
watchOS Apple Watch
tvOS Apple TV
visionOS Apple Vision Pro

⚠️ Pegadinha: iOS não é o sistema operacional dos Macs. Mac utiliza macOS.

Origem do macOS — Darwin e XNU

O macOS possui forte relação histórica com sistemas Unix.

Darwin — base tecnológica de código aberto utilizada no desenvolvimento dos sistemas Apple. Combina:

  • Kernel
  • BSD
  • Mach
  • Outros componentes

XNU (X is Not Unix) — kernel utilizado pelo macOS. Combina tecnologias de:

  • Mach
  • BSD
  • Componentes desenvolvidos pela Apple

⚠️ Pegadinha: O macOS não utiliza o kernel Linux. Seu kernel é o XNU.

Elementos da Interface Gráfica

O macOS utiliza uma interface gráfica integrada ao sistema com os seguintes elementos:

  • Mesa (Desktop) — área principal de trabalho
  • Dock — acesso rápido a aplicativos
  • Barra de Menus — menus e status do sistema
  • Finder — gerenciador de arquivos
  • Spotlight — busca integrada
  • Central de Controle — configurações rápidas
  • Central de Notificações — alertas e widgets
  • Mission Control — organização de janelas e espaços
  • Launchpad — lançador de aplicativos

Interface do macOS — Mesa, Dock e Barra de Menus

Finder — Gerenciador de Arquivos

O Finder é o principal gerenciador de arquivos do macOS.

Funções:

  • Criar pastas
  • Abrir, copiar, mover e renomear arquivos
  • Excluir e pesquisar
  • Visualizar e organizar arquivos

🧠 Comparação: Finder ↔ Explorador de Arquivos do Windows (funcionalmente semelhantes, mas não idênticos).

Finder — Gerenciador de Arquivos do macOS

Dock — Acesso Rápido

O Dock é uma área de acesso rápido a aplicativos e arquivos.

Pode apresentar:

  • Aplicativos fixados
  • Aplicativos em execução
  • Pastas e arquivos
  • Lixeira

⚠️ Pegadinha: Dock ≠ Barra de Tarefas do Windows. São componentes diferentes com funções semelhantes, mas não idênticas.

Barra de Menus e Spotlight

Barra de Menus — fica na parte superior da tela e pode apresentar:

  • Menu Apple
  • Menu do aplicativo ativo
  • Status da rede, som, bateria
  • Spotlight, Central de Controle
  • Data e hora

Spotlight — mecanismo de busca integrado. Pesquisa:

  • Arquivos, pastas e aplicativos
  • Mensagens, documentos, contatos
  • Configurações e informações diversas
  • Também realiza cálculos e conversões

🧠 Bizu: Spotlight = busca rápida do sistema.

Mission Control e Áreas de Trabalho Virtuais

Mission Control — fornece uma visão geral das janelas abertas e dos espaços de trabalho.

Funções:

  • Organização de janelas
  • Alternância entre espaços
  • Visualização de aplicativos
  • Gerenciamento de desktops virtuais

Áreas de Trabalho Virtuais — permitem separar atividades em diferentes espaços.

Exemplo:

  • Desktop 1 → Estudos
  • Desktop 2 → Trabalho
  • Desktop 3 → Navegação

🧠 Bizu: Mission Control = visualizar e organizar espaços e janelas.

Pegadinha

Finder ≠ Explorador de Arquivos

Finder é o gerenciador de arquivos do macOS.

Explorador de Arquivos é o gerenciador de arquivos do Windows.

São equivalentes funcionais, mas não são o mesmo software e pertencem a sistemas operacionais diferentes.

Pegadinha

Command + W vs Command + Q

Command + W — fecha a janela/aba atual (não encerra o aplicativo).

Command + Q — encerra o aplicativo completamente.

Não são a mesma coisa.

Forçar Encerramento

Quando um aplicativo deixa de responder, utilize:

Command + Option + Esc

A janela exibe os aplicativos em execução e permite solicitar o encerramento forçado de um aplicativo problemático.

🧠 Comparação:

  • Windows: Ctrl + Shift + Esc → Gerenciador de Tarefas
  • macOS: Command + Option + Esc → Forçar Encerrar Aplicativos

Capturas de Tela

O macOS possui atalhos próprios para captura:

Atalho Função
Command + Shift + 3 Captura a tela inteira
Command + Shift + 4 Permite selecionar uma região
Command + Shift + 5 Abre ferramentas adicionais de captura e gravação

APFS — Apple File System

O APFS é o sistema de arquivos desenvolvido pela Apple para dispositivos modernos.

Foi projetado especialmente para tecnologias atuais como SSD e memória flash.

Recursos:

  • Clonagem
  • Snapshots
  • Criptografia
  • Compartilhamento eficiente de espaço
  • Containers e volumes

⚠️ Pegadinha: APFS não é o kernel do macOS. É um sistema de arquivos.

HFS+ (Mac OS Extended) foi utilizado amplamente em versões anteriores do macOS.

Diagrama do sistema de arquivos APFS

Estrutura de Diretórios

O macOS possui uma estrutura Unix-like.

Principais diretórios:

Diretório Função
/ Raiz do sistema
/Users Diretórios dos usuários (similar ao /home no Linux)
/Applications Aplicativos instalados
/System Componentes fundamentais do sistema
/Library Recursos e arquivos do sistema e aplicativos
/Users/Shared Pasta compartilhada entre usuários
/Volumes Dispositivos montados
/private Dados privados do sistema

🧠 Bizu: /Users no macOS possui função semelhante ao /home no Linux.

Diretório Pessoal e Lixeira

Diretório pessoal — normalmente em /Users/nome.

No Terminal, ~ representa o diretório pessoal do usuário atual.

Lixeira — arquivos excluídos pela interface gráfica passam pela Lixeira antes da remoção definitiva.

  • Permite recuperar arquivos enquanto estiverem nela

⚠️ Pegadinha: Enviar para a Lixeira não é o mesmo que apagar imediatamente do armazenamento.

Extensões de Arquivos

Extensão Tipo
.app Aplicativo (estrutura de diretórios)
.pdf Documento PDF
.jpg / .png Imagem
.mov / .mp3 Vídeo / Áudio
.zip Arquivo compactado
.dmg Imagem de disco (Disk Image)
.pkg Pacote instalável

⚠️ Pegadinha: Um .app não deve ser entendido simplesmente como um executável isolado no mesmo modelo do .exe do Windows. Internamente, é uma estrutura de diretórios organizada.

Monitor de Atividade

O Monitor de Atividade é a ferramenta do macOS para acompanhar o funcionamento do sistema.

Permite observar:

  • CPU
  • Memória
  • Energia
  • Disco
  • Rede
  • Processos

🧠 Comparação: Monitor de Atividade ↔ Gerenciador de Tarefas do Windows (funcionalmente semelhantes, mas não idênticos).

Monitor de Atividade — Processos e Desempenho

CPU, Memória e Processos

CPU no Monitor de Atividade — verifica o uso do processador pelos processos. Ajuda a identificar:

  • Programas consumindo muito processamento
  • Processos travados
  • Carga elevada

Memória — apresenta informações relacionadas ao uso de RAM. Ajuda a identificar aplicativos que estejam utilizando recursos excessivos.

🧠 Bizu: GUI → Monitor de Atividade | Terminal → ps / top / kill

Mecanismos de Segurança

A Apple utiliza várias camadas de segurança:

Mecanismo Função
Gatekeeper Controle de execução de software (verifica assinatura e procedência)
FileVault Criptografia de dados do disco
SIP (System Integrity Protection) Proteção da integridade do sistema
Secure Boot Inicialização segura (hardware)
Sandboxing Isolamento/restrição de recursos
Assinatura de código Verifica autenticidade do software
Permissões e Privacidade Controle de acesso a câmera, microfone, localização, etc.
Atualizações de segurança Correções regulares do sistema

Gatekeeper — Controle de Execução

Gatekeeper é uma tecnologia de segurança do macOS que ajuda a impedir a execução de software malicioso ou não confiável.

Verifica:

  • Assinatura do aplicativo
  • Identificação do desenvolvedor
  • Notarização
  • Origem do software

⚠️ Pegadinha: Gatekeeper não é simplesmente um antivírus tradicional. É um mecanismo de segurança para controle da execução de software.

FileVault e SIP

FileVault — fornece criptografia para proteger os dados armazenados no Mac. Especialmente importante em casos de roubo ou perda do computador.

🧠 Bizu: FileVault = criptografia

SIP (System Integrity Protection) — mecanismo de segurança que impede que processos (mesmo com privilégios elevados) alterem determinados componentes críticos do sistema.

⚠️ Pegadinha: SIP não é antivírus, não é firewall, não é sistema de arquivos. É uma camada de proteção da integridade do sistema.

Sandbox e Privacidade

Sandbox — restringe o acesso de aplicativos a determinados recursos do sistema. O objetivo é limitar o impacto de um aplicativo comprometido ou malicioso.

🧠 Bizu: Sandbox = isolamento/restrição

Privacidade — o macOS permite controlar o acesso de aplicativos a recursos como:

  • Câmera e microfone
  • Localização
  • Contatos, calendário, fotos
  • Arquivos e acessibilidade

Essas permissões podem ser gerenciadas nas configurações de privacidade e segurança.

Pegadinha

Segurança — Mecanismos Diferentes

⚠️ Não confunda:

  • Gatekeeper → controle de execução
  • FileVault → criptografia
  • SIP → integridade do sistema
  • Sandbox → isolamento
  • Firewall → filtragem de rede (outro mecanismo)

Cada um possui uma função específica.

Usuários — Administrador e Padrão

O macOS permite diferentes tipos de contas:

Tipo Descrição
Administrador Privilégios elevados — pode instalar software, alterar configurações e gerenciar usuários
Usuário padrão Atividades cotidianas, com menos privilégios
Usuário somente compartilhamento Acesso restrito a recursos compartilhados
Usuário convidado Acesso temporário (quando habilitado)

⚠️ Pegadinha: Administrador não significa que todas as proteções do sistema deixam de existir. Mecanismos como SIP continuam ativos.

Apple Account e iCloud

Apple Account (antiga Apple ID) — utilizada para acesso a diversos serviços Apple.

iCloud — conjunto de serviços de nuvem da Apple:

  • Armazenamento e sincronização
  • Fotos, contatos, calendários, notas
  • Arquivos (iCloud Drive)
  • Senhas (Keychain)
  • Backup de dispositivos compatíveis
  • Find My (localização)

⚠️ Pegadinha: iCloud e iCloud Drive não são exatamente a mesma coisa.

  • iCloud = ecossistema de serviços em nuvem
  • iCloud Drive = parte destinada ao armazenamento e sincronização de arquivos

Time Machine — Backup

Time Machine é o sistema de backup integrado ao macOS.

Permite:

  • Realizar cópias de segurança automáticas
  • Restaurar arquivos, pastas e configurações
  • Recuperar o sistema em caso de problemas

⚠️ Pegadinha: Time Machine não é simplesmente um serviço de sincronização. Está relacionado principalmente a backup e recuperação.

🧠 Bizu:

  • Time Machine → backup
  • iCloud → sincronização/nuvem

AirDrop e Continuidade

AirDrop — compartilhamento direto entre dispositivos Apple compatíveis próximos.

Pode enviar:

  • Fotos, vídeos, documentos
  • Links e contatos

Continuidade — integração entre dispositivos Apple:

  • Handoff → continuar atividade de um dispositivo em outro
  • Universal Clipboard → copiar em um dispositivo, colar em outro
  • Continuidade da câmera
  • Compartilhamento de conexão

⚠️ Pegadinha: AirDrop ≠ iCloud. AirDrop é compartilhamento direto (próximo); iCloud é serviços de nuvem e sincronização.

Apple Silicon — Arquitetura ARM

A Apple passou a utilizar seus próprios chips baseados em arquitetura ARM para os Macs.

Família: M1, M2, M3, M4, M5.

SoC (System on a Chip) — integra diversos componentes em um único chip:

  • CPU
  • GPU
  • Neural Engine
  • Controladores
  • Memória e outros componentes

⚠️ Pegadinha: Apple Silicon utiliza arquitetura diferente dos Macs Intel (x86-64).

Transição: Intel x86-64 → Apple Silicon ARM

Chip Apple Silicon M1

Rosetta 2 — Compatibilidade

Rosetta 2 permite executar muitos aplicativos desenvolvidos originalmente para Macs Intel em Macs com Apple Silicon.

Realiza a tradução necessária para executar código x86-64 na nova arquitetura ARM.

⚠️ Pegadinha: Rosetta 2 não é um sistema operacional, nem um processador, nem o kernel. É uma tecnologia de tradução/compatibilidade.

Terminal do macOS

O macOS possui um Terminal baseado no ambiente Unix.

Pode ser utilizado para:

  • Executar comandos
  • Administrar arquivos
  • Diagnosticar problemas
  • Gerenciar processos
  • Automatizar tarefas
  • Administrar rede

Shells comuns:

  • Zsh (padrão em versões recentes)
  • Bash

⚠️ Pegadinha: Versões recentes do macOS utilizam zsh como Shell padrão.

🧠 Bizu: O Terminal do macOS utiliza muitos dos mesmos comandos Unix/Linux.

Permissões no macOS

Assim como em sistemas Unix, arquivos possuem permissões:

Permissão Valor Significado
r 4 Leitura
w 2 Escrita
x 1 Execução

Exemplo:

  • rwx = 7
  • rw- = 6
  • r-x = 5

Comando chmod — altera permissões.

Exemplo:

chmod 755 arquivo
  • Proprietário → rwx (7)
  • Grupo → r-x (5)
  • Outros → r-x (5)

Rede no macOS

O macOS possui várias ferramentas Unix para diagnóstico de rede:

Comando Função
ping Teste de conectividade
ifconfig Configuração de interfaces
networksetup Configuração de rede (ferramenta Apple)
netstat Estatísticas de rede
route Tabela de roteamento
scutil Configurações do sistema
dig / nslookup Consultas DNS
curl Requisições HTTP
ssh Acesso remoto seguro

⚠️ Atenção: Em ambientes Apple modernos, algumas ferramentas tradicionais Unix podem possuir diferenças em relação ao Linux.

20 Pegadinhas Clássicas

  1. macOS não é iOS.
  2. Mac não é sistema operacional — Mac é a linha de computadores.
  3. XNU não é Linux — é o kernel do macOS.
  4. Finder não é exatamente o Explorador de Arquivos — são equivalentes funcionais, mas não idênticos.
  5. Dock não é Barra de Tarefas.
  6. Spotlight não é apenas um navegador — é uma ferramenta de pesquisa integrada.
  7. Time Machine não é apenas sincronização — é principalmente backup e recuperação.
  8. iCloud não é apenas armazenamento — é um conjunto de serviços de nuvem.
  9. Gatekeeper não é simplesmente antivírus — é um mecanismo de segurança.
  10. FileVault não é firewall — é criptografia.
  11. SIP não é antivírus — é proteção da integridade do sistema.
  12. Rosetta 2 não é emulador de sistema operacional — é tecnologia de tradução para compatibilidade.
  13. APFS é sistema de arquivos — não é kernel.
  14. Zsh é Shell — não é sistema operacional.
  15. Swift é linguagem de programação — não é sistema operacional.
  16. AirDrop não é iCloud.
  17. Administrador não significa ausência de mecanismos de segurança.
  18. Command + W não é igual a Command + Q.
  19. Command + Option + Esc é usado para forçar encerramento de aplicativos.
  20. Apple Silicon utiliza arquitetura diferente dos Macs Intel.
