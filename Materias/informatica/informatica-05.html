O que é Informática

1 min de leitura

Explicação

O que é Informática

Informática é o estudo do tratamento automatizado da informação por meio de computadores. Todo sistema informatizado é formado por três elementos essenciais: Hardware, Software e Peopleware.

Explicação

Sistema informatizado

Um sistema informatizado é composto por:

  • Hardware (parte física)
  • Software (parte lógica)
  • Peopleware (elemento humano)

Esses três trabalham em conjunto para processar dados e gerar informações.

Explicação

Hardware

Parte física do computador. Componentes que podemos tocar e ver. Exemplos: CPU, teclado, monitor, HD, placa-mãe, mouse.

Conceito

Componentes de hardware

Explicação

Software

Parte lógica — programas e instruções. Controla e instrui o hardware. Não tem forma física — não pode ser tocado. Exemplos: Windows, Word, Chrome, antivírus.

Conceito

Ícones de programas (software)

Explicação

Peopleware

O elemento humano do sistema. Quem usa, opera e programa o computador. Terceiro elemento essencial — sem usuário, o sistema está incompleto.

Conceito

Usuário utilizando computador

Bizu

Bizu

Mnemônico para lembrar

Hardware = físico (toca) | Software = programa (não toca) | Peopleware = usuário.

Atenção

Pegadinha

Hardware ≠ Software

Hardware e Software não são sinônimos nem intercambiáveis. Um é físico, o outro é lógico; ambos são necessários, mas são conceitos distintos.
