Equações do 2º Grau

1 min de leitura

Explicação

Incógnita ao quadrado: ax² + bx + c = 0, com a ≠ 0. Possui até duas raízes reais.

Fórmula e cálculo

Bhaskara

x = (−b ± √Δ)/(2a), com Δ = b² − 4ac. Δ > 0: duas raízes reais distintas. Δ = 0: uma raiz (raízes iguais). Δ < 0: nenhuma raiz real. Exemplo: x² − 5x + 6 = 0 → Δ = 25 − 24 = 1 → x = (5 ± 1)/2 → x₁ = 3, x₂ = 2.

Fórmula e cálculo

Relações de Girard

Soma das raízes: x₁ + x₂ = −b/a. Produto: x₁·x₂ = c/a. Útil quando a questão pede soma ou produto sem calcular as raízes.

Bizu

Dica

Equações incompletas (b = 0 ou c = 0) têm atalho: fatore ou isole x².
